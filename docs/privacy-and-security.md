# PortKiller Pet — 이 프로그램이 무엇을 읽고 무엇을 읽지 않는가

사내 배포 전 보안 검토에 함께 제출하는 문서다.
"안 한다"는 말이 아니라 **코드에서 그 기능을 쓸 수 없게 만들어 둔 것**이 요점이다.

## 한 줄 요약

바탕화면에 캐릭터를 띄우는 장식 프로그램이다.
**외부로 나가는 통신이 없고**, 입력 내용을 읽지 않으며, 기록은 본인 PC에만 남는다.

## 읽는 것 / 읽지 않는 것

| | 내용 | 근거 |
|---|---|---|
| 읽음 | 마지막 입력 이후 지난 시간 (숫자 하나) | `ActivityMonitor.cs` — `GetLastInputInfo` |
| **안 읽음** | 어떤 키를 눌렀는지 | 키 상태를 읽는 함수를 호출하지 않는다 |
| **안 읽음** | 마우스 커서 위치 | 커서 좌표를 읽는 함수를 호출하지 않는다 |
| **안 읽음** | 어디를 클릭했는지, 무엇을 클릭했는지 | 클릭 대상을 조회하지 않는다 |
| **안 읽음** | 창 제목, 실행 중인 프로그램 이름 | 해당 API를 호출하지 않는다 |
| **안 읽음** | 화면 내용, 파일 내용, 클립보드 | 해당 API를 호출하지 않는다 |

## 쓰지 않기로 한 기술

의도적으로 배제했다. 기능이 아쉬워도 넣지 않는다.

- **전역 키보드/마우스 훅 (`SetWindowsHookEx`)** — 입력을 가로채는 방식.
  백신·EDR이 키로거로 판정하는 대표 패턴이라 처음부터 설계에서 뺐다.
- **실행 중 코드 컴파일** — `csc.exe` 등으로 런타임에 코드를 만들어 실행하는 방식.
  정적 검사를 우회하는 기법으로 분류되므로 쓰지 않는다.
- **자기 자신을 교체하는 자동 업데이트** — 새 실행 파일을 받아 배치 파일로 덮어쓰는 방식.
  악성코드의 전형적 동작이라 쓰지 않는다. 새 버전은 정식 배포 경로로만 내려간다.
- **관리자 권한 요구** — `app.manifest`에서 `asInvoker`로 고정.

## 네트워크

**통신 코드가 없다.** 업데이트 확인도 하지 않는다.
방화벽/프록시 로그에 이 프로그램 이름이 나타날 일이 없다.

## 저장되는 것

경로: `%APPDATA%\PortKillerPet\`

- `save.json` — 펫의 스탯, 성장 단계, 누적 집중 시간(초), 활동한 날짜 목록(YYYY-MM-DD)
- `save.bak` — 직전 세이브 1세대

폴더를 지우면 흔적이 남지 않는다. 레지스트리는 아래 한 곳만 쓴다.

## 시작 프로그램 등록

- 위치: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, 값 이름 `PortKillerPet`
- **기본값은 꺼짐.** 사용자가 트레이 메뉴에서 직접 켤 때만 등록된다.
- 현재 사용자 영역(HKCU)만 쓴다. 시스템 전역(HKLM)은 건드리지 않는다.

## 배포

- 서명된 실행 파일로만 배포한다.
- 메신저로 zip을 돌리는 방식은 쓰지 않는다. 사내 정식 배포 경로를 통한다.
- 빌드는 트리밍(`PublishTrimmed`)과 단일 파일 묶기를 사용하지 않는다.
  오탐의 주 원인이며, `Directory.Build.props`에서 전 프로젝트 공통으로 꺼두었다.

## 확인 방법

위 주장은 코드에서 직접 확인할 수 있다. 외부 함수 호출은 아래 세 곳이 전부다.

```
src/PortKiller.Platform/ActivityMonitor.cs   GetLastInputInfo
src/PortKiller.App/NativeMethods.cs          GetWindowLongPtrW, SetWindowLongPtrW
src/PortKiller.Platform/AutostartManager.cs  레지스트리 (Microsoft.Win32.Registry)
```

`src/` 아래에서 `DllImport`를 검색하면 이 목록이 전부인지 바로 확인된다.

> 위 주장은 **배포되는 앱 코드(`src/`) 기준**이다.
> `scripts/verify-clickthrough.ps1` 은 개발용 검사 도구라 커서를 옮기는 함수를 쓴다.
> 이 파일은 빌드에 포함되지 않으며 배포물에 들어가지 않는다.
창 함수 둘은 창을 Alt+Tab 목록에서 빼는 용도이며, 입력과 무관하다.

클릭 통과는 코드가 하는 일이 없다. 투명한 픽셀을 윈도우가 알아서 처리한다.
