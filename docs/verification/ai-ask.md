# AI 물어보기 실측 기록

> 2026-09-15 / Windows 11 Pro 26200 / .NET 9.0.318

## 무엇을 어떻게 확인했나

| 확인 | 방법 | 결과 |
|---|---|---|
| 프롬프트 → 엔터 → 답 | `scripts/verify-ask.ps1` (실제 키 입력·실제 엔터) | PASS |
| 열쇠 등록·암호화·삭제 | `scripts/verify-ai-keys.ps1` | PASS |
| 통신 실패 처리 14가지 | `AiClientTests` (가짜 응답기) | 74/74 |
| 실제 Gemini 호출 | 우리 클라이언트 코드로 1회 | "안녕!" 수신 |
| 실제 OpenAI 호출 | — | **안 해봤다** (아래 참고) |

## 진짜 호출은 한 번만 했다

자동 검사는 **네트워크를 건드리지 않는다.** 이유 셋이다.

1. 부를 때마다 **돈이 나간다.** 검사를 돌릴 때마다 요금이 붙으면 아무도 안 돌린다.
2. 열쇠가 있어야 도는 검사는 **열쇠 없는 사람이 못 돌린다.**
3. 인터넷이 끊긴 자리에서 검사가 빨갛게 되면, 그게 코드 문제인지 망 문제인지 알 수 없다.

그래서 `AiClientTests` 는 **가짜 응답기**를 끼워 넣고 "이런 응답이 오면 사용자 화면에
무엇이 뜨는가"만 본다 — 401·403·404·429·5xx·시간 초과·망 끊김·깨진 JSON·빈 응답.

다만 **통신 규격 자체가 맞는지는 가짜로 확인할 수 없다.** 그래서 Gemini 는 우리 클라이언트
코드 그대로 실제로 한 번 불러 봤다(위 표). **OpenAI 는 쓸 수 있는 열쇠가 없어서 못 해봤다 —
규격은 문서대로 맞췄지만 실제 응답으로 확인된 상태가 아니다.** 첫 사용자가 확인해야 한다.

## 검사가 실제로 잡은 버그 둘

검사를 나중에 붙였으면 사용자가 먼저 만났을 것들이다.

1. **빈 배열에서 터졌다.** `candidates` 가 빈 배열로 오면(안전 필터에 걸린 질문 등)
   `JsonNode` 의 `[0]` 이 범위 초과로 터진다 — 사용자에게는 영문 예외가 그대로 뜬다.
   Gemini 쪽에서 잡아서 OpenAI 쪽도 같이 고쳤다.
2. **한글이 JSON 이스케이프된다.** 보낸 본문에서 원문 조각을 찾는 방식은 늘 실패한다.
   검사를 "본문을 다시 파싱해서 맞는 칸에 들어갔는지" 보도록 바꿨다 — 바이트 모양이 아니라
   계약을 보는 것이 맞다.

## 검사 통로를 하나 만들었다 — 주소 바꿔치기는 안 썼다

물어보기 창은 트레이 메뉴로도 열리는데, **윈도우 11 이 새 트레이 아이콘을 숨김 영역에 넣어
자동 검사가 그 메뉴에 닿지 못한다.** 그래서 두 가지를 뒀다.

- `--open-ask` / `--open-ai-settings` — 켜자마자 그 창을 연다
- **펫 우클릭 메뉴에도 "물어보기"를 넣었다** — 이 메뉴는 자동 검사가 닿는다(돌보기 메뉴에서 확인됨)

그리고 `--stub-ai` — 통신을 아예 하지 않는 가짜 클라이언트를 끼운다.

> **주소를 환경변수로 바꿔치기하는 방식은 일부러 쓰지 않았다.**
> 처음에는 로컬 가짜 서버를 띄우고 `PORTKILLER_AI_BASEURL` 로 돌리려 했는데,
> 그러면 배포본에 **"아무 서버로나 보낼 수 있는 구멍"** 이 남는다. 보안 검토에서
> 가장 먼저 걸릴 자리다. 가짜 객체는 I/O 를 하지 않으므로 어디로도 나갈 수 없다.

## 열쇠가 정말 안전한지

`verify-ai-keys.ps1` 은 문서의 주장을 그대로 시험한다. 가짜 열쇠
`FAKE-KEY-FOR-TESTING-0123456789` 를 설정 창에 **타이핑해서** 등록한 뒤:

| 시험 | 결과 |
|---|---|
| `keys.dat` 안에 그 문자열이 평문으로 있나 (UTF-8·UTF-16 둘 다 검사) | **없음** |
| `save.json` 또는 `ai.json` 에 있나 | **없음** |
| "전부 지우기"로 파일이 실제로 사라지나 | **사라짐** |

암호화는 윈도우 DPAPI(현재 사용자 범위)다. 파일을 다른 PC·다른 계정으로 옮기면 복호화되지
않는다. 실측으로 확인: 평문 5바이트가 암호문 230바이트가 된다.

## 작은 판단 셋

- **엔터는 보내기, Shift+엔터는 줄바꿈.** 긴 질문에서 엔터가 전송이면 문단을 못 쓴다.
- **한글 조합 중 엔터는 무시한다.** 그걸 전송으로 받으면 마지막 글자가 빠진 채 날아간다
  (`e.ImeProcessedKey` 로 가른다).
- **묻는 중에는 다시 못 보낸다.** 엔터를 연타해도 요금이 여러 번 나가지 않는다.
- **답은 말풍선이 아니라 창에 뜬다.** 말풍선은 몇 글자짜리라 AI 답을 담으면 화면을 덮고,
  지나가던 사람도 읽게 된다. 펫은 "답 왔어!" 한마디만 한다.
